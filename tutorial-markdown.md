# Tutorial Básico de Markdown

Este é um tutorial introdutório sobre como usar Markdown, uma linguagem
simples de marcação para formatar textos.

## 1. Títulos

Use o símbolo `#` para criar títulos. Quanto mais `#`, menor o título:

```markdown
# Título 1
## Título 2
### Título 3
```

## 2. Ênfase

- **Negrito**: `**texto**`
- *Itálico*: `*texto*`
- ~~Tachado~~: `~~texto~~`

## 3. Listas

Listas não ordenadas usam `-` ou `*`:

```markdown
- Item 1
- Item 2
```

Listas ordenadas usam números:

```markdown
1. Primeiro
2. Segundo
```

## 4. Links e imagens

- Link: `[texto](https://exemplo.com)`
- Imagem: `![descrição](caminho/imagem.png)`

## 5. Blocos de código

Use crases triplas para destacar código:

````markdown
```python
print("Olá, mundo!")
```
````

## 6. Citações

Use `>` para citações:

```markdown
> Esta é uma citação.
```

## Conclusão

Markdown é amplamente usado em arquivos README, documentação e blogs.
Pratique criando seus próprios arquivos `.md`!
